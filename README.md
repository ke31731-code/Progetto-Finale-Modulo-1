Descrizione:
Questo è un progetto del master in Python di EPICODE, basato sull'analisi di dati delle vendite di una catena di negozi, con dataset creato a mano seguendo uno schema ben preciso
Dataset
Il dataset è stato creato manualmente a scopo didattico e contiene:
- Data della vendita
- Negozio
- Prodotto
- Quantità venduta
- Prezzo unitario Il codice, scritto interamento in Python(v. 3.13), è munito di documentazione scritta per le operazioni più importanti utilizzate all'interno del progetto.

Punti chiave: 
Sono state utilizzate 3 librerie fondamentali per la data analisys.
1.NumPy per operazioni sugli array ed estrazione di dati ben precisi su cui sono state effettuate delle analisi statistiche(es: media, deviazione standard, vendite in percentuale, valori min e max...)
2.Pandas per consentire la creazione di un dataframe strutturato con righe e colonne ben specifiche per le operazioni da svolgere. Anche qui sono state utilizzate funzioni di statistica per calcolare informazioni importanti
3.Matplotlib necessario per la visualizzazione dei dati attraverso l'utilizzo di grafici interattivi.
